# SQLForge Retrospective Template

## Purpose

本模板用于每轮阶段性交付、复杂任务批次或服务拆分后复盘，确保后续工作不会只留下“做了什么”，而是同时留下“为什么偏差”“哪些规则需要补强”“哪些缺口进入下一轮”。

## When To Use

- 一个阶段结束后
- 一个跨服务或跨前后端批次结束后
- 一个高风险缺陷修复完成后
- 一次规则/文档治理专项结束后

## Closeout Rule

- 复盘不能替代验证日志。
- 复盘不能把未实现项写成完成项。
- 复盘后若产生长期约束，必须继续追加到规则库或历史账本，而不是只停留在本模板实例中。
