## 三、关键特性与痛点映射

| 痛点 | 方案特性 | 实现机制 |
|:---|:---|:---|
| 无法预估新SQL资源消耗 | SQL意图理解 + 样本压测 + 资源估算 | AST解析风险标记,样本外推全量,输出CPU/内存/磁盘需求 |
| 不知扩容多少 | 容量规划模型 + M/M/c排队论 | 历史负载聚类,并发-延迟曲线,量化Worker/内存缺口 |
| 优化器选错计划 | 执行计划枚举 + 统计信息老化模拟 | Hint强制多计划生成,测试计划稳定性边界,建立防护策略 |
| 数据倾斜 | 倾斜感知采样 + 专项压测矩阵 | Skew系数分层,构造极端倾斜数据集,验证Skew Join策略 |
| 并发不足/排队 | 梯度加压 + 租户混压 + 队列模拟 | 识别吞吐量拐点,验证物理隔离有效性,模拟Resource Group限制 |
| 扫描全量数据 | 谓词下推验证 + 分区裁剪检测 | 对比下推前后扫描行数,验证分区键有效性 |
| Join耗时过多 | Join专项分析 + 计划枚举 | 检测Cartesian Product/Broadcast失效/重复关联,建议CTE优化 |
| 多次关联同表 | 重复关联检测 + 物化建议 | AST模式识别,建议临时表物化,量化性能提升 |
| 非必要排序 | 排序消除验证 + 性能对比 | 识别ORDER BY必要性,对比取消前后延迟 |
| 返回结果过多 | 结果集规模预警 + 聚合下推建议 | 检测大结果集,建议分页或预聚合 |
| 表达式重复计算 | 表达式复用检测 | 识别相同子表达式,验证物化复用效果 |
| 谓词下推失效 | 下推有效性验证 | 对比Filter下推前后执行计划与扫描量 |
| 分桶失效 | 分桶有效性验证 | 检测Bucket Join触发,避免意外Shuffle |
